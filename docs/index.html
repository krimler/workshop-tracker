There is no single list of academic workshops. Each one runs its own call for papers, with its own deadline, on its own page, so finding them means checking conferences one by one. This page collects them: the workshop, its parent conference, the submission deadline, the location. The data is rebuilt daily from public sources, and the whole table below runs in your browser.
